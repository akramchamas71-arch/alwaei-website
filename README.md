# موقع "الوعي" - منصة سياسية للنشر

موقع إخباري/تحليلي سياسي عربي (RTL) مبني بتقنية Next.js، مع لوحة تحكم كاملة لإدارة المقالات والأقسام.

## المتطلبات

- **Node.js 22 أو أحدث** (ضروري - الموقع يستخدم `node:sqlite` المدمج في Node، وهو غير متوفر في إصدارات أقدم).
- لا حاجة لتثبيت أي قاعدة بيانات منفصلة (MySQL/Postgres) - قاعدة البيانات ملف SQLite واحد يُنشأ تلقائياً.

## ⚠️ ملاحظة مهمة جداً حول الاستضافة

هذا الموقع يجب أن يعمل كخادم Node.js دائم (Persistent Server) — مثل VPS عادي، أو خدمات مثل Railway وRender وDigitalOcean App Platform.

**لا تنشره على استضافة Serverless مثل Vercel (الخطة المجانية العادية)** لأن قاعدة البيانات ملف محلي (SQLite) يُكتب على القرص، والاستضافات الـ Serverless لا تحافظ على الملفات بين الطلبات - أي مقالة تضيفها ستختفي. إذا كانت استضافتك الحالية (cPanel تقليدي) لا تدعم Node.js، الأسهل هو نشر التطبيق على خدمة مثل Railway أو Render (لهما خطط مجانية/رخيصة) وتوجيه الدومين الذي تملكه إليها عبر DNS (خطوات ذلك أدناه).

## التشغيل محلياً (للتجربة)

المشروع يأتي مع قاعدة بيانات جاهزة (`data/alwaei.db`) تحتوي على الأقسام وحساب الأدمن والمقالات الأولية - لا حاجة لتشغيل أي أمر "زرع" بيانات إضافي.

```bash
npm install
npm run build
npm run start
```
الموقع سيعمل على http://localhost:3000

> إذا حذفت مجلد `data/` وأردت البدء من جديد بقاعدة بيانات فارغة، شغّل `npm run seed` لإعادة إنشائها.

## بيانات حساب لوحة التحكم

- الرابط: `/admin/login`
- البريد الإلكتروني: `admin@alwaei.com`
- كلمة المرور: `Waei#2026Secure`

**غيّر كلمة المرور فوراً بعد أول نشر فعلي** (يمكن تغييرها مباشرة في قاعدة البيانات، أو حذف حساب الأدمن وإعادة إنشائه بمتغيرات بيئة مختلفة - راجع القسم التالي).

## متغيرات البيئة (اختياري لكن موصى به)

أنشئ ملف `.env` في جذر المشروع قبل تشغيل `npm run seed`:

```
SESSION_SECRET=اكتب-هنا-نص-عشوائي-طويل-وسري
SEED_ADMIN_EMAIL=بريدك@example.com
SEED_ADMIN_PASSWORD=كلمة-مرور-قوية-من-اختيارك
```

- `SESSION_SECRET` يُستخدم لتوقيع جلسات تسجيل الدخول - **ضروري تغييره في الإنتاج** (أي نص عشوائي طويل يكفي).
- إذا لم تُحدد `SEED_ADMIN_EMAIL`/`SEED_ADMIN_PASSWORD`، سيُستخدم الحساب الافتراضي أعلاه.

## هيكل المشروع

```
src/app/(site)/        الصفحات العامة (الرئيسية، الأقسام، المقالة، البحث)
src/app/admin/         لوحة التحكم (تسجيل الدخول، المقالات، الأقسام)
src/lib/db.ts          الاتصال بقاعدة البيانات وإنشاء الجداول
src/lib/data.ts        دوال قراءة/كتابة المقالات والأقسام
src/lib/auth.ts        تسجيل الدخول والجلسات
src/components/        عناصر الواجهة (الهيدر، الفوتر، بطاقة المقالة، الشعار...)
scripts/seed.mjs       زرع البيانات الأولية (الأقسام + حساب الأدمن + مقالات تجريبية)
data/alwaei.db         ملف قاعدة البيانات (يُنشأ تلقائياً - يجب نسخه احتياطياً بانتظام!)
public/uploads/        صور المقالات المرفوعة من لوحة التحكم
```

## ⚠️ نسخ احتياطي لقاعدة البيانات

كل المحتوى (المقالات، الأقسام) محفوظ في ملف واحد: `data/alwaei.db`. يُنصح بشدة بعمل نسخة احتياطية دورية لهذا الملف (وملفات `public/uploads/`) لأنه إذا فُقد، يُفقد كل المحتوى معه.

## محتوى يحتاج إكمالاً

مقالة "لو عاد السيد موسى الصدر اليوم… إلى مَن سيطلب تسليم السلاح؟" حُفظت كمسودة (غير منشورة) لأنه تعذّر الوصول تلقائياً إلى نصها الكامل من مصدرها الأصلي. الصق النص الكامل من لوحة التحكم (تعديل المقالة) ثم غيّر حالتها إلى "منشور" لإتمام نشرها.

## خيارات النشر (اختر واحداً)

### الخيار 1: Railway أو Render (الأسهل، موصى به)

1. أنشئ حساباً على [railway.app](https://railway.app) أو [render.com](https://render.com).
2. ارفع هذا المشروع إلى مستودع GitHub خاص بك.
3. اربط المستودع بخدمة "Web Service" جديدة على المنصة، مع التأكد من اختيار Node.js 22.
4. أوامر البناء والتشغيل:
   - Build: `npm install && npm run build && npm run seed`
   - Start: `npm run start`
5. **مهم**: فعّل "Persistent Disk / Volume" وثبّته على مجلد المشروع (أو على الأقل على `data/` و`public/uploads/`) حتى لا تُفقد المقالات عند كل إعادة نشر.
6. أضف متغيرات البيئة (`SESSION_SECRET` وغيرها) من إعدادات المشروع في لوحة تحكم المنصة.
7. بعد نجاح النشر ستحصل على رابط مؤقت (مثل `alwaei.up.railway.app`) - اربط دومينك الخاص به من إعدادات "Custom Domain"، ثم أضف سجل CNAME (أو A، حسب تعليمات المنصة) في لوحة تحكم الدومين عندك.

### الخيار 2: خادم VPS خاص بك (DigitalOcean، Hetzner، إلخ)

```bash
# على السيرفر:
sudo apt update && sudo apt install -y nodejs npm   # تأكد من الحصول على Node 22+
git clone <رابط مستودعك> alwaei && cd alwaei
npm install
npm run build
npm run seed
npm install -g pm2
pm2 start npm --name alwaei -- run start
pm2 save && pm2 startup   # لتشغيل الموقع تلقائياً بعد أي إعادة تشغيل للسيرفر
```
ثم:
- ركّب Nginx كـ reverse proxy يوجّه الدومين إلى `localhost:3000`.
- استخدم `certbot` لتفعيل HTTPS مجاناً (Let's Encrypt).
- في DNS الخاص بالدومين، أضف سجل A يشير إلى IP السيرفر.

## التخصيص لاحقاً

- **الشعار**: `src/components/Logo.tsx` - تصميم مبدئي بسيط، يمكن استبداله بشعارك الفعلي عندما يجهز (ضع ملف الصورة في `public/` واستبدل الكود بـ `<img>`).
- **الألوان**: `src/app/globals.css` - المتغيرات في أعلى الملف (`--brand`, `--gold`, إلخ).
- **الأقسام**: تُدار بالكامل من لوحة التحكم (`/admin/categories`) - إضافة وحذف بدون لمس الكود.
- **دومين ثابت للصور المرفوعة**: تأكد أن مجلد `public/uploads/` محفوظ ضمن التخزين الدائم (persistent disk) على منصة الاستضافة.
